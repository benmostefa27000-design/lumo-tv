# Lumo

Lecteur IPTV perso (Xtream) pour téléphone Android, Google TV et Fire TV : accueil façon streaming, profils, direct, films, séries, rattrapage, synchro téléphone ↔ TV.

**Télécharger la dernière version :** https://github.com/benmostefa27000-design/lumo-tv/releases/latest/download/lumo-tv.apk

Chaque envoi sur `main` compile l'APK (GitHub Actions) et publie une nouvelle version ; l'appli propose la mise à jour toute seule.
